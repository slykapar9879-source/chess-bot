# Chess Bot

A chess bot with a graphical interface built using **SDL2/SDL3**.  
This project features a visual chessboard, basic AI logic, and a sidebar for game settings.

---

## 🖼️ Features

- 8x8 chessboard with clear, crisp squares
- Sidebar for game controls and AI settings
- Basic AI opponent (expandable with more advanced algorithms)
- Cross-platform: Windows, Linux, and macOS support
- Clean SDL-based rendering with room for custom graphics

---
